# Daydrop public website

Product, support, privacy, terms, and data deletion information for Daydrop by Medha Arcot.

Live site: https://vadirajmkulkarni.github.io/daydrop-site/

This repository contains public static website files only. No application configuration, service credentials, user records, or app source belong here. The website uses system fonts, local CSS and an original SVG mark, with no analytics, advertising or build dependencies.

GitHub Pages serves the main branch root. All links support the `/daydrop-site/` project path.

Daydrop 1.0 is available for iPhone. This checkout prepares the 1.1 website update, clearly labelled coming soon until that app update is released. The generic and India App Store URLs were verified on November 3, 2026 as HTTP 200 pages identifying Daydrop: Focus & Small Wins. Policy changes must match the app’s actual behavior.

The 1.1 copy explains derived local streaks, weekly activity, any-task focus, and retained wins. No additional data collection, scripts, cookies, dependencies, or service integrations are introduced. Publication remains a separate parent-owned step.


The three website screenshots in `assets/` are byte-identical copies of the accepted Today, Focus, and Wins RGB JPEGs from the Daydrop 1.1.0 (3) native QA run on November 3, 2026. The app screenshot manifest records their genuine capture and encoding provenance. They contain synthetic example tasks/history, retain their full original 1206×2622 ratio, and are not retouched or composited. The unused Later capture is excluded. The public website labels the forthcoming 1.1 experience separately from the existing App Store download.
