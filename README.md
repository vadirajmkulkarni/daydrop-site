# Daydrop public website

Product, support, privacy, terms, and data deletion information for Daydrop by Medha Arcot.

Live site: https://vadirajmkulkarni.github.io/daydrop-site/

This repository contains public static website files only. No application configuration, service credentials, user records, or app source belong here. The website uses system fonts, local CSS and an original SVG mark, with no analytics, advertising or build dependencies.

GitHub Pages serves the main branch root. All links support the `/daydrop-site/` project path.

Daydrop is in development and does not yet have a public App Store listing. Policy changes must match the app’s actual released behavior.
